# Phase 5: ハードクリーンアップ + リネーム伝播

> 全体計画: `docs/overhaul/plan.md` を必ず先に読むこと。AGENTS.md の規則に従うこと。
> Phase 2・3・4 すべての完了後に着手。

## 目的

移行期間用の互換コードを削除して最終形にし、リネームの安全伝播を実装し、
AGENTS.md を新アーキテクチャに合わせて更新する。

## 変更対象

* **DSL互換の削除**(`src/dsl/`):
  * `id=` 属性のパース対応と `SerializeDslOptions.includeIds`
  * `parent=` / `branch=` 属性の受理(非推奨診断ごと削除。以後は構文エラー)
* **JSON形式の残骸削除**: `src/document/documentFormat.ts` のうちインポータが
  使わない部分、`documentMigration.ts`(既に死んでいる)、スナップショット型の
  `printLayout` ミラー・`selected*` フィールドの型定義残り。
  レガシーインポータ自体は**残す**(ユーザーが不要と明言したら別途削除)。
* **cadUiStore の死んだ状態**: DslPanel窓・廃止ダイアログ・パラメータ編集
  モード関連のフラグを削除。
* **コマンドIDの整理**: no-op化した旧コマンドIDを削除。旧ID→新挙動の対応表を
  `docs/overhaul/` に確定版として置き、ユーザーのショートカット設定ファイルが
  未知IDを含んでいても安全に無視されることを確認。
* **リネーム伝播の実装**: リネームコマンド=モデル上のrename+ブリッジが
  「その要素の行」と「その名前を参照している全ての文」(直接参照・
  `名前.端点` 派生形・式内参照・修飾名 `グループ.名前`・printLayoutの
  `place` 参照・view/roleの参照)を再シリアライズし、**1 Undoステップ**で
  行パッチする。`textPatch.ts` の自然な拡張として実装。
* **AGENTS.md 更新**: 保存形式(`.nui` DSLテキスト、`docs/overhaul/plan.md` と
  `docs/dsl.md` への参照)、エディタアーキテクチャ(CodeMirrorアダプタ層の
  隔離規則、「ファイル全体再シリアライズ禁止・行スプライスのみ」の規則)、
  パラメータ編集ポリシー(読み取り専用インスペクタ+カーソルジャンプ)、
  「Source of truth」セクションのファイル一覧更新。
* **ROADMAP.md / docs/dsl.md** — 現状に合わせて更新。

## 守るべき不変条件

* リネームは参照を壊さない: 伝播後のテキストを再コンパイルして
  dangling参照が増えていないことをコミット時にassert(dev)。
* リネーム先が同スコープで衝突する場合は**拒否+明確なエラー**
  (自動連番リネームしない)。
* 削除済み名への既存dangling参照は従来どおり「生トークン+明示的依存診断」の
  まま(リネーム伝播の対象にしない)。
* 1リネーム=1 Undoステップ。
* インポータ(`legacyImport.ts`)は削除しない。

## Phase開始時点の前提

* Phase 0〜4 すべて完了済み。アプリは `.nui` 正準・常設エディタ・読み取り専用
  インスペクタ・コマンドライン作図で動作している。
* `parent=` / `id=` を含む文書はレガシーインポータ経由でのみ生成され得る
  状態になっている(インポータ出力に含まれていないことを確認してから
  パース対応を削除すること)。

## 完了条件

* 上記削除がすべて完了し、grepで `includeIds` / `parent=` / `branch=` /
  `printLayout` ミラー / 廃止コマンドID の参照が残っていない。
* リネーム伝播が全参照形式で動作。
* AGENTS.md / ROADMAP.md / docs/dsl.md が新アーキテクチャを正しく記述。
* フルチェック: `npm test` / `npm run test:parity` / `npm run build` /
  `npm run lint` / `npm run desktop:build`(notarization警告は想定内)。

## 必須テスト

* リネーム伝播の行列: 直接参照 / `名前.端点` / 式内参照 / 修飾名
  (`グループ.名前`、グループ自体のリネーム含む)/ printLayout `place` /
  view・role参照。それぞれ「参照行だけがパッチされ、他の行は不変」を確認。
* リネーム衝突の拒否。
* リネームのUndoで全参照が一括で戻ること。
* `id=` / `parent=` を含むテキストが構文エラー診断になること。
* 未知コマンドIDを含むショートカット設定の安全な無視。

## やってはいけないこと

* レガシーインポータの削除。
* リネーム衝突時の自動修復(連番付与等)。
* 「ついで」の機能追加。本Phaseは削除・整理・リネーム伝播・ドキュメント
  更新のみ。
* AGENTS.md の全面書き換え(変更点のみ差分更新。既存の製品原則は維持)。
